# HERCULE — your local AI assistant

100% on-device. No cloud, no tracking, no account.

## Download

Grab the latest Windows installer from [**Releases**](https://github.com/heeranpaul5366ssshvib-beep/HERCULExLINK/releases) — look for HERCULE-Setup-*-x64.exe.

## First run

1. Install and launch HERCULE.
2. Open **Model Manager** and download a model (auto-resumes if interrupted).
3. Press **Play**, then chat — privately, offline, on your PC.

## Notes

- The app runs models locally via a bundled inference engine.
- Your chats, tools and plugins stay on your machine.
